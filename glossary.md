# Glossary

**AAF**: anti-alias filter ahead of an ADC; 10 MHz low-pass on the radar receive chains (Ch 8)
**AEC-Q100**: automotive IC stress qualification; SKU-1 header (Ch 2)
**AHB-Lite / APB**: AMBA buses; the high-speed 32-bit bus and the low-speed peripheral bus on SKU-2 and SKU-4 (Ch 3, 5)
**ASIL-B/C/D**: ISO 26262 automotive safety integrity levels; D is highest (Ch 2, 5, 9, 10)
**Attach part**: a part sold one per node or board; the market tile on SKU-5 and SKU-6 (Ch 1, 6, 7)
**AXI4 crossbar / matrix**: AMBA AXI interconnect; 64-bit on SKU-9 and the platform, 128-bit on D100 (Ch 10, 11, 12)
**AXI-REALM**: per-manager real-time monitoring and regulation units on an AXI matrix (Ch 12)
**BA (sliding-window)**: bundle adjustment over recent frames in the D100 pose engine (Ch 11)
**BCD / HV / MS**: bipolar-CMOS-DMOS power process; high-voltage option; mixed-signal process (Ch 14)
**BIST**: built-in self-test; frame-freeze detection on SKU-8 (Ch 9)
**Brokaw bandgap**: classic bipolar voltage reference; 1.20 V, 12 ppm/°C on SKU-3 (Ch 4)
**CAN-FD / CAN-XL**: flexible-data-rate and extra-long CAN generations (Ch 6, 10)
**CFAR**: constant false-alarm rate detection; cell-averaging on SKU-7 (Ch 8)
**Chopper-stabilised comparator**: offset-cancelled comparator for accurate thresholds; SKU-6 (Ch 7)
**CORDIC**: shift-and-add rectangular-to-polar conversion in the FOC datapath (Ch 2)
**Curvature-corrected bandgap**: reference with second-order temperature correction; 10 ppm/°C on SKU-6 (Ch 7)
**Deglitch counter**: digital filter that ignores comparator spikes shorter than N clock counts; 8 µs at 8 MHz (Ch 7)
**DICE latch / TMR**: SEU-tolerant storage cell / triple modular redundancy; on the SKU-3 sequencer (Ch 4)
**DLMS/COSEM**: utility metering data model and protocol on the SKU-2 UART (Ch 3)
**DMA**: direct memory access controller; moves data without CPU copies (Ch 3, 5, 11, 12)
**DShot600**: digital ESC protocol at 600 kbit/s; D100 ESC output (Ch 11)
**EKF**: extended Kalman filter; D100 pose estimation at 30 Hz (Ch 11)
**EVITA-full HSM**: automotive hardware security module profile with its own processor and crypto (Ch 10)
**FAULTn / RESETn / PGOOD**: active-low fault, active-low reset, power-good outputs (Ch 4, 5, 7)
**FDIR**: fault detection, isolation and recovery (Ch 5)
**Failsafe island**: D100's hardware link monitor → safe-state FSM → independent ESC path (Ch 11)
**FMCW**: frequency-modulated continuous-wave radar; range from beat frequency (Ch 8)
**FOC**: field-oriented control of motor currents in the rotor frame (Ch 2)
**Foldback**: current limit that lowers allowed current as the output collapses (Ch 4)
**Freedom from interference**: ISO 26262 separation of safety and non-safety software; MPU + bus firewall on SKU-9 (Ch 10)
**HBT (SiGe)**: silicon-germanium heterojunction bipolar transistor; ft 350 / fmax 450 GHz on IHP SG13G2 (Ch 8)
**HMR**: hybrid modular redundancy; cores switchable between independent and redundant modes (Ch 12)
**I²t curve**: fuse trip characteristic based on current squared times time (Ch 10)
**IEC 61000-4-2 vs HBM**: system-level ESD (contact/air) vs component human-body model; not interchangeable (Ch 6)
**LDMOS / thick oxide**: high-voltage transistor options that make 5–120 V stages possible at 130 nm (Ch 2, 4, 6, 9)
**Lockstep (2-cycle skew)**: duplicated cores offset in time and compared (Ch 5, 10, 11)
**MiM capacitor**: metal-insulator-metal capacitor; precise analog capacitance (Ch 4)
**MIMO virtual array**: TX × RX elements formed by separating transmitters; 2 × 4 = 8 on SKU-7 (Ch 8)
**OBI / Regbus / TL-UL / TCDM**: bus protocols in the platform's safe, peripheral, secure and accelerator domains (Ch 12)
**OSR / sinc³**: oversampling ratio / third-order decimation filter after a ΣΔ modulator; OSR 256 on SKU-2 (Ch 3)
**OTP trim**: one-time-programmable calibration bits; 6-bit on SKU-3, 5-bit on SKU-6 (Ch 4, 7)
**Park / Clarke transforms**: three-phase ↔ two-axis stationary ↔ rotating-frame conversions (Ch 2)
**Peak-current-mode control**: buck control using inductor current each cycle, with slope compensation (Ch 4)
**PIL-5**: fifth Positive Indigenisation List; BEL 17-inch rugged SXGA display item, Dec 2027 (Ch 9)
**PMP / MPU**: RISC-V physical memory protection / memory protection unit (Ch 5, 10)
**PSRR**: power-supply rejection ratio; 60 dB at 100 Hz on SKU-3 (Ch 4)
**PTP 802.1AS / TSN 802.1Qbv**: time synchronisation / time-aware shaping for bounded Ethernet latency (Ch 10)
**RV64GCH**: 64-bit RISC-V with general, compressed and hypervisor extensions; the platform's Linux host (Ch 12)
**SAR ADC**: successive-approximation ADC; 12-bit telemetry on SKU-3 (Ch 4)
**SEU**: single-event upset from a particle strike flipping a bit (Ch 4)
**SOME/IP / DoIP**: automotive service middleware / diagnostics over IP (Ch 10)
**SPM**: scratchpad memory; deterministic alternative to caches (Ch 12)
**SXGA**: 1280 × 1024; 108 MHz pixel clock at 60 Hz (Ch 9)
**TCON**: timing controller for a display panel (Ch 9)
**THD-15**: total harmonic distortion measured to the 15th harmonic (Ch 3)
**UCIe**: chiplet interconnect standard; deliberately not used in the SiP (Ch 13)
**VCOM**: LCD common-electrode voltage (Ch 9)
**VIO**: visual-inertial odometry; camera + IMU pose without GNSS (Ch 11)
**Window watchdog**: watchdog that faults on a kick too early or too late; 1 ms / 10 ms (Ch 4, 7)
**ΣΔ (delta-sigma)**: oversampled ADC architecture; 24-bit DG-AFE6 (Ch 3)
